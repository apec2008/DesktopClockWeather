Desktop Clock Weather V1.1 - Fast Startup 확인

기본 시작 방식은 Task Scheduler 로그온 트리거이며, 등록 실패 시 Startup 폴더 방식으로 자동 fallback합니다.

확인 방법
1. STARTUP_INSTALL_REPORT.txt에서 ActiveMode를 확인합니다.
2. TaskSchedulerFast이면 재부팅 후 바탕화면 표시 시점부터 첫 Clock 창까지 시간을 측정합니다.
3. 권장 기준: 15초 이내 좋음, 15~25초 허용, 25초 초과 시 개선 검토.
4. 중복 실행, 프로필 누락, 위치 이상이 없는지 확인합니다.

문제가 생기면 Switch_To_Standard_Startup.bat를 실행하여 Startup 폴더 방식으로 되돌릴 수 있습니다.
프로필/도시/색상/크기/위치/StartupState는 보존됩니다.
